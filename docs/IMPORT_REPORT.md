3. **לא התקבלו קבצי מדיה מורשים.** לפי ההנחיה, ייבוא נעשה רק מקבצים מקומיים שבעלי התוכן אישרו.
4. **לא פורסם תוכן ״כאילו הפרופיל העלה אותו״.** יצירת עסק ב־Beautigo על שם יוצר/ת אמיתי/ת תציג אותם כמשתתפים בפלטפורמה, עם מחירים, זמינות וביקורות. זה מנוגד להנחיה (״Do not invent … participation in Beautigo״) ולכלל שלא להתחזות לאנשי מקצוע אמיתיים.

## מה כן נבנה כדי שאפשר יהיה לייבא נכון

- **שדות מקור בכל פריט מדיה:** `sourceReelUrl`, `sourceProfileUrl` ו־`creator` (`src/domain/types.ts`). אף ערך לא ממולא אוטומטית או מנוחש.
- **״קרדיט ומקור״ ביצירת תוכן** (`src/screens/composer.tsx`): עסק שמעלה קובץ שקיבל עליו רשות מדביק את קישור הרילס והפרופיל המקוריים ואת שם היוצר/ת. רק קישורי אינסטגרם, פייסבוק או טיקטוק מתקבלים.
- **קרדיט על הרילס בפיד:** תגית ״קרדיט: <שם> ↗״ שמובילה למקור.

## איך משלימים ייבוא אמיתי

1. מקבלים מבעל/ת התוכן את קובץ הווידאו (MP4) ואישור שימוש.
2. מוודאים שהחשבון שפרסם את הרילס הוא אכן היוצר/ת.
3. בעסק לדוגמה (או בעסק של היוצר/ת עצמם, אם הם מצטרפים בפועל) פותחים ״יצירה״ ← ״גלריה״, ממלאים ״קרדיט ומקור״ ומפרסמים.
4. מעדכנים את הדוח הזה: מעבירים את השורה ל״יובאו בהצלחה״.

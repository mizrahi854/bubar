# Beautigo — דמו אינטראקטיבי

רשת חברתית לטיפוח עם הזמנת תורים: פיד רילס, גילוי עסקים לפי עיר, פרופילים עסקיים, הזמנה מתוך השראה, יומן עסקי וניהול פלטפורמה.
עברית מלאה (RTL), ש״ח, אזור זמן ישראל. האפליקציה רצה כולה בדפדפן — אין שרת, אין מפתחות ואין שירותים חיצוניים.

## הפעלה

דרוש Node.js 20 ומעלה.

```bash
npm install
npm run dev          # http://localhost:5173
```

גרסת ייצור מקומית:

```bash
npm run build
npm run preview      # http://localhost:4173
```

בדיקות:

```bash
npm run typecheck    # TypeScript
npm run lint         # oxlint
npm test             # Vitest — לוגיקת הזמנות והרשאות
npm run test:e2e     # Playwright — 12 המסעות הנדרשים, מצבים נוספים, סטוריז ושכבה חברתית (מפעיל שרת פיתוח בפורט 5174)
```

## תפקידי דמו

ההחלפה בין תפקידים נמצאת ב**מצב דמו** (פרופיל ← ״מצב דמו · החלפת תפקיד״, או בסרגל הצד בדסקטופ). זו **לא** הזדהות אמיתית: אין סיסמאות, וההרשאות נאכפות רק בשכבת הפעולות המקומית.

| תפקיד | משתמש | מה אפשר לבדוק |
|---|---|---|
| אורח/ת | — | פיד, גילוי, פרופילים. לייק, שמירה או הזמנה פותחים בקשת התחברות, וההזמנה ממשיכה מאותו שלב |
| לקוחה | דנה כהן | הזמנה מרילס, מקדמה מדומה, שינוי מועד וביטול, ביקורת אחרי תור שהושלם, אוספים, הודעות |
| בעלת עסק | מאיה רוזן — סטודיו נובה | יצירת רילס/תמונה/קרוסלה, יומן יום/שבוע, אישור בקשות, שירותים, צוות, נתונים, Google Calendar מדומה |
| צוות | נועה לוי — סטודיו נובה | גישה ליומן ולתורים של עצמה בלבד |
| מנהלת פלטפורמה | — | דיווחים, מודרציה, אישור/השעיה של עסקים, תמיכה בתורים, יומן פעולות |

״איפוס הדמו״ במסך מצב הדמו מחזיר את הנתונים למצב ההתחלתי.

## מה עובד מקומית

- **פיד**: בשבילך / במעקב / קרוב אליי. וידאו אחד פעיל, עוצר מחוץ למסך ובטאב מוסתר. השתקה, לייק בהקשה כפולה, תגובות, שמירה לאוסף, שיתוף (Web Share או העתקת קישור), דיווח וחסימה, וגם ״למה זה מוצג לי״.
- **קביעת תור מהפוסט**: העסק, השירות ואיש המקצוע נבחרים מראש, וההשראה והמקור נשמרים בתור.
- **גילוי**:
  - חיפוש ומסננים: עיר, מרחק (רק עם מיקום), קטגוריה, שירות, סגנון, איש מקצוע, מחיר, דירוג, תאריך ו״פנוי היום״.
  - צ׳יפים פעילים, איפוס, ומצב ריק עם ״הרחבה לכל הארץ״.
  - תצוגת רשת, רשימה ומפת דמו סכמטית.
- **פרופיל עסק ואיש מקצוע**: לשוניות, פוסטים נעוצים, עריכה על ידי הבעלים, ביקורות עם תגובת העסק.
- **הזמנה**:
  - שלבים: שירות ← איש מקצוע או ״כל אחד״ ← מועד ← השראה והערה ← סיכום.
  - מקדמה ויתרה מוצגות, ואישור מיידי או ידני לפי השירות.
  - זמינות מחושבת לפי שעות, משך, מרווח, הפסקות, תורים וחסימות. אין חפיפות.
  - המחיר נשמר ברגע ההזמנה. בקשות ותשלומים שפג תוקפם משחררים את המועד.
- **תורים**:
  - הלקוח/ה יכולים לשנות מועד (אטומי, עם אישור), לבטל לפי מדיניות, להזמין שוב ולכתוב ביקורת (רק אחרי השלמה, פעם אחת).
  - העסק יכול לאשר, לדחות, לבטל עם סיבה, לסמן ״הושלם״ או ״לא הגיע/ה״, ולהוסיף הערה פנימית.
- **יומן עסקי**: יום/שבוע, סינון צוות, תור ידני, חסימת זמן והפסקות.
- **הודעות** עם הקשר תור והשראה, סימון ״לא נקרא״, תשובות מהירות, דיווח וחסימה. **התראות** בתוך האפליקציה בלבד.
- **הגדרות**:
  - מראה: בהיר/כהה/מערכת, עוצמת זכוכית, הפחתת שקיפות, הפחתת תנועה וגודל טקסט.
  - מדיה: כתוביות, ניגון אוטומטי, חיסכון בנתונים, ועמעום מדיה בלבד (לא בהירות המסך).
  - פרטיות, חשבונות חסומים והתראות לפי קטגוריה.
- **יצירת תוכן**: העלאה או ספריית דמו, תמונת שער מפריים, חיתוך **מדומה** (חלון ניגון, הקובץ לא נערך), כיתוב, תגיות, עיר, שירות ואיש מקצוע. טיוטה, פרסום, עריכה ומחיקה.
- **מצלמה בתוך האפליקציה**: וידאו עד 60 שניות או תמונה, מצלמה קדמית/אחורית, טיימר 3/10 שניות ופילטרים שנצרבים בקובץ (Canvas + MediaRecorder). צריך הרשאת מצלמה. בתצוגה המוטמעת של Claude המצלמה חסומה, והמסך מסביר את זה.
- **עורך**: פילטרים וטקסט על התמונה או הסרטון. גוררים את הטקסט למקום, ואפשר לבחור סגנון וצבע.
- **סטוריז ל־24 שעות**: מגש סטוריז בגילוי וטבעת סביב תמונת העסק. צפייה בהקשה (קדימה/אחורה), החזקה עוצרת. כפתור ״קביעת תור״ לשירות מקושר, תגובה שנכנסת להודעות העסק, ולייק. העסק רואה מי צפה, ואפשר לשתף פוסט לסטורי.
- **שכבה חברתית**: תשובות לתגובות (רמה אחת, כמו באינסטגרם), לייק לתגובה, נעיצת תגובה על ידי העסק, תיוג @ עם התראה, ועמוד לכל #תגית.
- **תובנות יוצרים** (ניהול ← נתונים): זמן צפייה ממוצע, צפייה עד הסוף, שימור אחרי 1/3/5 שניות, מקורות תנועה, עוקבים חדשים, שיתופים, ביצועי כל רילס עד התחלת הזמנה, וצפיות בסטוריז. האירועים נספרים מקומית.
- **השראה מאינסטגרם** (`/#/inspiration`, וגם כרטיס אחרי כל 4 רילסים ב״בשבילך״): 20 רילסים ציבוריים בהטמעה הרשמית של אינסטגרם, עם קרדיט ליוצרים ו״מצאו עסק לשירות הזה״. שום קובץ לא הורד, והיוצרים לא מוצגים כעסקים ב־Beautigo.
- **קרדיט ומקור**: בכל פריט מדיה אפשר לשמור קישור לרילס המקורי, קישור לפרופיל ושם היוצר/ת. הקרדיט מוצג על הרילס. המערכת לא מורידה תוכן מקישורים. ראו [`docs/IMPORT_REPORT.md`](docs/IMPORT_REPORT.md).
- **ניהול פלטפורמה**: כל פעולה רגישה דורשת סיבה ונרשמת ביומן הפעולות.
- **שמירה**:
  - הנתונים נשמרים ב־localStorage, וקבצים שהועלו ב־IndexedDB.
  - הנתונים מסונכרנים בין טאבים, ורענון הדף לא מאבד מצב.

## Beautigo Pro — מערכת ניהול לעסק (Supabase + Vercel)

נכנסים בכתובת `/#/biz`. עמוד ההזמנות ללקוחות נמצא ב־`/#/p/<כתובת-העסק>`.

- **יומן**: תצוגות רשימה, יום, שבוע וחודש, סינון לפי איש צוות, תור חדש, שינוי מועד, ביטול, אישור, "לא הגיע/ה" וחסימת זמן.
- **לקוחות**: חיפוש, וכרטיס לקוח עם היסטוריה, תגיות, יום הולדת, העדפות ותמונות לפני ואחרי.
- **הודעות**: הלקוח/ה כותבים מעמוד ההזמנות או מתוך תור, והעסק עונה מתיבת ההודעות, בזמן אמת ועם תשובות מהירות.
- **דוחות והכנסות**: הכנסות לאורך זמן, צפי, לקוחות חוזרים, אי־הגעה, פילוח לפי צוות ושירות, ומפת שעות עמוסות.
- **כל היכולות** (`/#/biz/tour`): סיור עם קישור ישיר לכל יכולת.
- **פיד פעילות חי**: רישום לקוח, זימון, ביטול ורשימת המתנה, בזמן אמת (Supabase Realtime).
- **רשימת המתנה**: כשתור מתבטל, מי שממתין/ה לאותו שירות, יום ושעה מסומן/ת אוטומטית (trigger במסד הנתונים).
- **התחברות**: קוד SMS (Twilio דרך Supabase) או Google.
- **צוות**: הזמנה לפי מספר טלפון. עובד/ת רואה רק את היומן שלו/ה.
- **Google Calendar אמיתי**: OAuth בשרת של Vercel, סנכרון תורים ליומן, וזמנים תפוסים ביומן נחסמים במערכת. הטוקנים לא מגיעים לדפדפן.

בלי משתני סביבה המערכת רצה ב**תצוגה מקדימה** עם נתוני דוגמה בדפדפן, וקוד ה־SMS הוא `123456`.

**הקמת החשבונות צעד אחר צעד:** [`docs/SETUP.md`](docs/SETUP.md). המשתנים הנדרשים מפורטים ב־[`.env.example`](.env.example).

```
supabase/migrations/   סכמה: טבלאות, RLS, מניעת חפיפות, RPC להזמנה ולביטול, triggers לפעילות ולרשימת המתנה
supabase/tests/        בדיקות הסכמה על Postgres מקומי (bash supabase/tests/run.sh)
api/google/*           פונקציות Vercel: connect, callback, calendars, calendar, sync, push, disconnect, cron
src/biz/               האפליקציה: backend (Supabase או תצוגה מקדימה), מסכים, סשן
```

## מה מדומה

| תחום | בדמו | בגרסה אמיתית |
|---|---|---|
| התחברות | בחירת חשבון דמו, ללא סיסמה | הזדהות בשרת (OTP בטלפון), סשנים מאובטחים |
| תשלום מקדמה | `DemoPayments`: הצלחה או כשל לבחירה, ללא שדות כרטיס | ספק סליקה עם דף תשלום מתארח, webhook מאומת בשרת |
| Google Calendar | `SimulatedGoogleCalendar`: חיבור, בחירת יומן, סנכרון, כשל `invalid_grant`, ניתוק | OAuth עם PKCE בשרת, מיפוי event id, syncToken (טיפול ב־410), retry, יבוא זמנים תפוסים כחסימות |
| התראות | בתוך האפליקציה בלבד | פוש, SMS ואימייל דרך ספק |
| מפה | ייצוג סכמטי לפי קואורדינטות הערים | ספק מפות |
| חיתוך וידאו | חלון ניגון שנשמר בפוסט | קידוד בשרת |
| סטוריז ומצלמה | קבצים נשמרים רק בדפדפן הזה (IndexedDB) | אחסון מדיה וקידוד בשרת |
| קידום (״ממומן״) | קמפיינים ומדדים מדומים, ללא חיוב | חיוב, תקרות תקציב, דוחות |
| נתונים | אירועים נספרים מקומית | אנליטיקה בשרת |

ממשקי ההחלפה נמצאים ב־`src/integrations/` וב־`src/data/repository.ts`. מניעת חפיפה בין תורים נבדקת בצד הלקוח; בגרסה אמיתית היא תתבצע בטרנזקציה בשרת עם constraint במסד הנתונים (ראו הערה ב־`src/domain/booking.ts`).

## מדיה

כל הסרטונים והתמונות הם **איורים מקוריים שנוצרו בקוד** (`scripts/sample-art.html` ו־`scripts/generate-sample-media.ts`), ומסומנים באפליקציה ״תוכן לדוגמה · איור מקורי״. לא הורד ולא הועתק תוכן של אנשים אמיתיים, והעסקים והאנשים בדמו בדיוניים.

## מבנה

```
src/domain/        מודל, זמינות והזמנות, הרשאות, דירוג פיד, חיפוש
src/data/          נתוני דמו (seed) ו־repository (localStorage + IndexedDB)
src/integrations/  תשלום, Google Calendar ושיתוף — מדומים, מאחורי ממשק
src/store/         מצב (Zustand) ופעולות עם בדיקות הרשאה
src/screens/       מסכים: לקוח, עסק (manage/), אדמין
src/ui/            רכיבי עיצוב, מעטפת וניווט, חלונות
tests/             Vitest (לוגיקה) ו־Playwright (מסעות, ב־tests/e2e)
docs/              צ׳קליסט דרישות, הערות התקדמות ומפת דרכים
```
